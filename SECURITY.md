# Security Policy

## Supported Versions

Security updates are applied to the latest deployment on the `main` branch.

| Version | Supported |
| :--- | :--- |
| `main` (latest) | Yes |

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately via GitHub Security Advisories rather than opening a public issue:

- Private report URL: https://github.com/AquilaXk/aquila-blog-web/security/advisories/new
- Do not include vulnerability details, reproduction steps, PoCs, or secrets in public Issues.
- Public evidence must include only information with tokens, cookies, personal data, and internal URLs removed or redacted.
